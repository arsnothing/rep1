# راه‌اندازی پایگاه دادهٔ SQL

سامانه به‌صورت پیش‌فرض بدون پایگاه داده کار می‌کند و گزارش‌ها را در
`data/reports.json` ذخیره می‌کند. برای فعال‌سازی MySQL/MariaDB:

## ۱) ساخت دیتابیس و جدول‌ها
اسکیمای زیر را روی سرور اجرا کنید (MySQL 5.7+ یا MariaDB 10.2+ به‌دلیل ستون‌های JSON):

```bash
mysql -u root -p < database/schema.sql
```

این کار دیتابیس `faraja_reports` و چهار جدول را می‌سازد:
- `reports` — جدول اصلی گزارش‌ها (بخش، زیربخش، محل، زمان و کل داده‌های فرم به‌صورت JSON).
- `report_incident_topics` — موضوعات «نوع جرم یا تخلف» هر گزارش و پاسخ‌های آن‌ها.
- `report_incident_details` — بخش‌های «همکاران و افراد مرتبط» و «نحوهٔ اطلاع».
- `report_documents` — فایل‌های پیوست.

## ۲) تنظیم اتصال
فایل نمونه را کپی و مقادیرش را پر کنید:

```bash
cp config/database.sample.php config/database.php
```

سپس `host`، `database`، `username` و `password` را ویرایش کنید (یا از متغیرهای
محیطی `DB_HOST`، `DB_NAME`، `DB_USER`، `DB_PASS` استفاده کنید).

به‌محض وجود `config/database.php` با `'enabled' => true`، هر گزارش جدید در
پایگاه داده ذخیره می‌شود. اگر اتصال برقرار نشود، سامانه به‌طور خودکار به ذخیره‌سازی
`reports.json` بازمی‌گردد تا هیچ گزارشی از دست نرود.

## نکتهٔ امنیتی
فایل `config/database.php` را در مخزن عمومی قرار ندهید و دسترسی به پوشهٔ
`config/` را از طریق وب ببندید (مثل پوشهٔ `data/` که `.htaccess` دارد).
